# Storybook Meadow

Ένα φιλικό online παιχνίδι ρόλων με όμορφα τοπία, σχεδιασμένο για παιδιά 10 χρονών. Οι παίκτες διαλέγουν το όνομα και το χρώμα στολής τους, εξερευνούν το λιβάδι, γνωρίζουν άλλους εξερευνητές και μοιράζονται το συναίσθημά τους.

## Χαρακτηριστικά

- 🌈 Ζωγραφισμένο λιβάδι με ουρανό, βουνά, λίμνη και λουλούδια.
- 🎨 Προσαρμογή χρώματος στολής του χαρακτήρα.
- 😄 Φούσκα συναισθήματος για να δείχνει πώς νιώθει ο παίκτης.
- 🌍 Πραγματικός χρόνος συγχρονισμός κινήσεων με Socket.IO.

## Ξεκίνημα

```bash
npm install
npm start
```

Η εφαρμογή εκτελείται στο `http://localhost:3000`. Άνοιξε το URL σε δύο διαφορετικές καρτέλες για να δεις πολλούς παίκτες ταυτόχρονα.

## Τεχνολογίες

- [Express](https://expressjs.com/) για την εξυπηρέτηση των στατικών αρχείων.
- [Socket.IO](https://socket.io/) για επικοινωνία πραγματικού χρόνου.
- HTML5 Canvas για την απεικόνιση του κόσμου.

## Ιδέες για επέκταση

- Προσθήκη mini-quests και απλών αποστολών συνεργασίας.
- Ασφαλές chat με εικονίδια αντί για ελεύθερο κείμενο.
- Συλλογή αντικειμένων με αφήγηση παραμυθιού.
